**Files** (`docs/canvases/`, docs only)

  the aggregate (section 6.6)"; the session canvas section "Facts the session cannot refuse"; the
  site power budget canvas, "This is Ohmline's **hot aggregate**" paragraph (cost per command grows
  with open requests, one mailbox per site, points to 15.8); the id token canvas on turning a

  the `Active` session state), so the writer can quote them alongside the code.

  …UnknownConnector, …ConnectorUnavailable, …ReservedForAnotherToken, …ConnectorFaulted)` with the

- `src/Charging/Ohmline.Charging.Domain/ChargePoints/ChargePoint.cs` (`public static class` at this
  tag, 132 lines). **Quote from `ch07-s04` for 7.4** (7.5 adds Evolve to the same file, 7.6 changes
  the class line):
  - `ReservationHold` = 15 minutes (line 15).
  - **The top-level table** `Decide(ChargePointState state, ChargePointCommand command,
    DecisionContext context)` (lines 17–36, with its summary): five rows. Row 1 is the factory `(Unregistered,
    RegisterChargePoint register) => Accept(new ChargePointRegistered(…))`; then `(Unregistered,
    ConnectorCommand)`, `(Registered, RegisterChargePoint)`, `(Registered chargePoint,
    ConnectorCommand onConnector)` which looks the connector up and either delegates or rejects
    `UnknownConnector`; and `(null, _) => throw DefaultState()`. **No discard on the command**: the
    closed intermediate `ConnectorCommand` makes `RegisterChargePoint | ConnectorCommand`
    exhaustive.
  - **The connector table** `Decide(ConnectorState state, ConnectorCommand command,
    DecisionContext context)` (lines 38–98, private): 35 rows grouped by command with blank lines
    between groups (Reserve, Cancel, Expire, Occupy, Release, Report/Clear fault, Make
    unavailable/available). Every state is spelled out (`Available or Occupied or Faulted or
    Unavailable`), never `_`, so a sixth connector state breaks the build. Guards come first,
    then an unguarded row per case (guards do not count toward exhaustiveness). Rows to quote:
    - `(Reserved held, ReserveConnector reserve) when held.HasExpiredAt(context.Now) =>
      Accept(Expiry(reserve, held), Reservation(reserve, context))` (two events from one
      decision; the clock is the context's).
    - `(Occupied current, OccupyConnector occupy) when current.SessionId == occupy.SessionId =>
      NoChange` (idempotency by state).
    - `(Occupied current, ReleaseConnector release) => Accept(new ConnectorReleased(…,
      current.SessionId))` (the event carries data from state, not from the command).
  - Helpers (lines 100–131): `Reservation` (expiry = `context.Now + ReservationHold`, summary "The
    expiry is decided here, from the context's time, and recorded"), `Expiry`, `Occupation`,
    error helpers `HeldForAnother`, `Unusable`, `Broken`, and the result helpers
    `NoChange { get; } = Accept()`, `Accept(params ImmutableArray<ChargePointEvent> events) =>
    Result.Ok(events)`, `Reject(ChargePointError error) => Result.Fail(error)`. **`params
    ImmutableArray<T>`** (C# 13 params collections) is what lets every row write
    `Accept(eventA, eventB)` or `Accept()`.
- `tests/Ohmline.Charging.Domain.Tests/DecisionAssertions.cs`: a C# 14 extension block

## Deviations from the outline (and why)

1. **Two extra charge point commands and events** (7.2): `MakeConnectorUnavailable` /
   `MakeConnectorAvailable`, `ConnectorMadeUnavailable` / `ConnectorMadeAvailable`. The outline's
   eight commands give no way into the outline's `Unavailable` state; an unreachable case is worse
   than none. They are operators' commands (closing a bay), modelled on OCPP's ChangeAvailability.
   Glossary, design-level board and Charging canvas updated.
2. **`SessionState` has `Active`, not `Charging`** (7.7). A type named `Charging` resolves to the
   namespace `Ohmline.Charging` everywhere outside its own namespace. Probe output with the type
   used from `Ohmline.Charging.Domain.Tests.Sessions`: `error CS0118: 'Charging' is a namespace but
   is used like a type`. Same trap as `Money` in 6.3. The `SessionState` summary and the glossary
   (new row "Active (session)") say so.
3. **`StartSession`/`SessionStarted` carry `Money PricePerKwh`** next to the outline's `TariffId` +
   `TariffVersion` placeholder (7.7). The spend cap cannot be checked without a price; 8.2

4. **`PriorityClass` moved to `Ohmline.SiteEnergy.Contracts/Budgets`** (7.8). The outline lists it

## Surprises and gotchas (for the writer)

- **`TheoryData<string>` and collection expressions:** `new([.. a, .. b])` is ambiguous in xUnit v3
  4.0.2: `error CS0121: The call is ambiguous between … 'TheoryData<string>.TheoryData(params
  string[])' and 'TheoryData<string>.TheoryData(params TheoryDataRow<string>[])'`. Use
  `new(a.Concat(b))`.
- **A record holding an `ImmutableArray` inside `Ok<T>`:** `Result.Ok([...]).ShouldBe(...)` fails
  even with equal events, because `Ok<ImmutableArray<T>>` is a record that compares the array by
  reference. Compare `.Value` element-wise (the `DecisionAssertions` helper does).
- **A switch expression whose arms are tuples of different case types has no natural type**:
  `(ChargePointEvent @event, ConnectorState next) = happened switch { … }` fails with `CS8131` /
  `CS8506`; declare the tuple type on a variable (`(ChargePointEvent Event, ConnectorState Next)
  row = …`).
- **`Enumerable.Min()` on `Power` would throw at run time** (no `IComparable`; the units implement
  `IComparisonOperators` only, as 6.8 found for Shouldly). The allocator uses `MinBy(power =>
  power.Kilowatts)`.
- **Lifted operators work on `Power?`**: `levels[index] += raise` and `levels[index] >=
  requests[index].MaxPower` compile and behave (a null level is "not admitted").
- **A static abstract member as a method group:** `events.Aggregate(state, TDecider.Evolve)`
  compiles without a lambda.
- **Static members in a union body** (`Initial`, `AllocationDecision.Of`) are fine; instance fields
  are still `CS9373`.
- **Nested case types** in a union's case list (`public union ChargePointError(
  ChargePointError.NotRegistered, …) { public sealed record NotRegistered(…); }`) compile and
  convert implicitly; verified with a probe before use.
- **Field names that equal a new case type** shadow it: a test field `Available` hid the new
  `Available` record (renamed `Free`).
