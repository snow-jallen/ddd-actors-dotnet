  person-to-person (fleet manager to duty officer). Key lesson: Northgate Grid *requests*,
  Ohmline *applies*; "rebalance" is not shard rebalancing.
- `03-failed-capture.md`: site `slc-west-garage`, connector `OHM-SLC-0107/2` (new names, used
  only here). Suspended by EV at 18:40, unplugged 19:15, 87.6 kWh; price USD 36.79 energy +
  USD 1.00 session fee + USD 8.00 idle fee (20 min × USD 0.40) = USD 45.79 against a
  USD 40.00 hold; TallyPay declines, Ohmline captures USD 40.00 and records a debt of USD 5.79;
  the billing specialist sends a reminder next morning. 11 sentences, 11 arrows. A "variation"
  paragraph: TallyPay does not answer; retries after 1, 5 and 30 minutes, then a debt.

**Arithmetic, checked:** 87.6 × 0.42 = 36.792 → 36.79; grace ends 18:55, unplug 19:15 → 20 idle
minutes; 36.79 + 1.00 + 8.00 = 45.79; 45.79 − 40.00 = 5.79. While charging, the price was
37.79, below the spend cap, so the cap never stopped charging; the idle fee alone pushes the
price over the hold. This is hotspot H3 in 4.2.

## ch04-s03: Process-Level EventStorming

**Files:** `docs/eventstorming/process-start-charging.md`, `process-settle-session.md`

- `process-start-charging.md` opens with the board's grammar as a `text` block:
  `person or external system -> command -> event -> policy -> command -> event -> ...`.
  The `flowchart LR` has exactly 15 nodes: Driver, Charge point, TallyPay; events Connector
  occupied, Token locked for session, Hold placed, Power allocated, Session started; commands
  Lock token for session, Place hold, Request allocation, Remote start; policies P1–P3. Tables:
  Commands (issued by, expected event, can be refused because), Policies P1–P6 (P4–P6 are the
  unhappy paths; **P6 is time-triggered**: "the session has not started 60 s after the remote
  start → release the allocation, void the hold and unlock the token", which is the energy-flow
  timeout of 15.5), Read models (Connector availability, Current site tariff, Session card, Site
  live board). Lessons: start charging is a chain held together by policies and a deadline (the
  charging journey of 15.2); hold before power is a business choice; the tariff snapshot comes
  from a read model that may be seconds old.
- `process-settle-session.md`: 15-node `flowchart LR`; "Session ended" fans out into two
  independent branches (release power; price → capture → captured / capture failed → debt).
  Policies P1–P9 (P6 = story 03's "capture the whole hold and record a debt for the rest", P7 =
  void when no energy was delivered, P8 = retries 1/5/30 min with the same idempotency key).
  Read models: Receipt, Session history, Open debts. The file says the capture chain "has to
  remember how many attempts it has made: that memory is what makes the chain a process rather
  than a set of reactions (Chapter 15)".

## Deviations from the outline

1. **No tests in 4.6.** The outline's code change lists only the two projects and their types,
   and the types have no behaviour. A test project would have had to be
   `tests/Ohmline.Charging.Domain.Tests` (created by 6.5 per the outline) or
   `tests/Ohmline.ArchitectureTests` (5.3), so creating either here would have taken another
   section's diff. The compiler is the check at this tag; the exhaustiveness facts above were
   verified in a throwaway project.
2. **Id token event names chosen here.** The outline names the id token's commands and replies
   (12.7) but not its events. The design-level board and the glossary use `TokenRegistered`,
   `TokenBlocked`, `TokenLockedForSession` and `TokenUnlocked`. The coder of 12.7 should use them
   or change the glossary in the same commit. Billing's event `PaymentCaptured` matches the
   port result of the same name in outline 15.2.
3. **Tag annotations** use the format of the earlier chapters and the task brief
   (`4.1 Domain Storytelling with Ohmline's people`), not `sample-architecture.md` §10's
   `chNN-sMM: <title>`; this is the known difference already noted for Chapter 1.
4. **Two new fictional site and connector names** appear only in story 03: `slc-west-garage`
   and `OHM-SLC-0107/2`, so that the failed capture is not at the depot.
